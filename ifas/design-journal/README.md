# Design Journal (DJ)

O Design Journal registra os aprendizados práticos, armadilhas técnicas e regras de engenharia descobertas durante a implementação no ecossistema IFAS.

Para registrar uma nova lição aprendida, utilize o template oficial em:
[`ifas/knowledge-base/templates/dj-template.md`](../knowledge-base/templates/dj-template.md)
